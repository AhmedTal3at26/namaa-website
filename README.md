# نماء 🌱 | منهج بناء الشخصية الإسلامية — موقع تفاعلي

موقع عربي أنيق يحوّل كتاب **«نماء — منهج بناء الشخصية الإسلامية من الرضاعة إلى ما بعد الجامعة»**
(مؤسسة المربي) إلى أداة عملية للأسر:

- ✅ **استبانة للوالدين** (33 عبارة) لتقييم الطفل عبر المجالات الـ11 مع حفظ تلقائي
- ✅ **تقرير مفصل** بالدرجات والمستويات والاقتراحات حسب المرحلة العمرية + خطة 30 يومًا + طباعة/PDF
- ✅ **7 صفحات مستقلة للمراحل** (0–2، 3–5، 6–8، 9–11، 12–14، 15–17، +18) تضم المجالات والمعايير والأنشطة
- ✅ تكبير/تصغير الخط (14–28px مع حفظ) + ثيم داكن/فاتح مع حفظ
- ✅ خط IBM Plex Sans Arabic (خط ثمانية الرسمي) + Aref Ruqaa + Amiri Quran

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة — لا يحتاج سيرفر.

## النشر عبر GitHub Pages

1. ارفع الملفات إلى مستودع GitHub (الفرع `main`، الجذر).
2. من صفحة المستودع: **Settings ← Pages ← Deploy from a branch ← `main` ← `/ (root)` ← Save**.
3. بعد دقيقة تقريبًا يصبح الموقع متاحًا على:
   `https://USERNAME.github.io/REPO/`

> ملف `.nojekyll` موجود في الجذر لمنع معالجة Jekyll وضمان عمل الصفحات والروابط كما هي.
